## 本地运行

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4174/prototype/index.html>。

原型使用原生 HTML、CSS 和 JavaScript，无构建步骤或运行时外部依赖。

## 文件入口

`PLAN.md` 和原始作业题目仅在本地维护，不随公开仓库发布。

| 文件 | 用途 |
|---|---|
| `PRD.md` | 产品设计和业务规则的权威来源 |
| `方案说明.md` | 最终提交的一页说明 |
| `AGENTS.md` | 后续 Agent 必须遵守的实现约束 |
| `CLAUDE.md` | 指向 `AGENTS.md` 的同源软链接 |
| `index.html` | 静态部署根入口，自动进入原型 |
| `prototype/index.html` | 可交互原型入口 |
| `tokens.css` | 原型共享视觉 token |

原型在单个入口中使用 hash 路由表达 9 个逻辑页面，避免多个 HTML 页面复制相同布局和状态。
